# 项目展示操作清单

入口：打开当前 FastAPI 的 `8010` 端口预览链接，并把路径改为 `/demo-ui`（例如 `http://127.0.0.1:8010/demo-ui`）。

| 操作 | 可展示功能 |
| --- | --- |
| 保持默认“星选生活 / CUS-1001”，点击“商品＋退货政策” | 知识库问答；右侧“知识来源”显示真实文档引用。 |
| 点击“订单查询”，再发送 `SS-2026-10002` | 多轮追问、会话上下文、订单归属校验和真实物流信息。 |
| 点击“退款资格”，再发送 `SS-2026-10001` | 基于订单状态和 YAML 规则的确定性退款资格判断。 |
| 点击“转人工” | 模拟人工升级，并在右侧看到 `MOCK-TKT-*` 工单。 |
| 将商家切换为“纸舟文具”，发送“这支笔防水吗？” | 无需改代码切换独立商家配置、数据与知识库。 |
| 将订单切换为 `PH-2026-001`，发送“我的订单到哪了？”再发送该订单号 | 第二商家的订单号规则及订单查询能力。 |
| 点击“▶ 一键完整剧本” | 连续演示知识问答、追问订单、退款资格、人工升级及事件生成。 |
| 点击“安全异常：不存在订单” | 明确失败而不编造订单数据。 |
| 查看底部“框架运营控制台” | 双商家能力、真实指标、Webhook 事件状态、配置版本和脱敏审计。 |

展示时始终展开右侧“执行观察”：可说明回答来自实际 Skill、工具 trace、规则与知识引用，而非预设文本。
